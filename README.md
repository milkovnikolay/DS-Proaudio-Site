# Сайт DS PROAUDIO

Официальный сайт DS PROAUDIO — российского производителя профессиональной акустики.

## О проекте

- Назначение: каталог продукции, информация о компании, портфолио, отзывы, контакты для клиентов.
- Домен: nikolaymilkov.com
- Хостинг: RU-CENTER (nic.ru)

## Структура

```
site/                 — сам сайт (то, что загружается на хостинг)
  *.html              — страницы
  *.css, *.js         — стили и скрипты
  assets/             — изображения, видео, данные (products.json, portfolio.json и др.)
  vendor/             — сторонние библиотеки
service-api/          — приёмник заявок с форм (Node.js); лежит вне site/, на хостинг вместе с сайтом не выгружается
Карта сайта.html      — карта страниц
*.xlsx                — рабочие таблицы: меню, продукция, портфолио
Что где лежит.txt     — описание содержимого папки
```

В репозиторий не попадают архивы (.zip, .rar), папки «Резервные копии» и «Видеоотзывы (исходники)» — история версий теперь хранится в самом Git.

## Публикация

Рабочая версия хранится в этом репозитории. Для публикации содержимое папки `site` загружается на хостинг RU-CENTER в корневую папку сайта.

Пароли и ключи (TG_TOKEN, TG_CHAT, STATS_KEY) задаются только на сервере через переменные окружения и в репозиторий не записываются.
